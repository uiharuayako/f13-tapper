# v1.0.0 验证记录

验证日期：2026-10-26。环境：Windows 11 x64、Python 3.12.12、Tcl/Tk 8.6、PyInstaller 6.22.3。

## 已通过

- 5 项单元测试：频率边界及 NaN/无穷值拒绝；低频等待可及时停止及重启；重复启动拒绝；输入错误停止；修饰键暂停/恢复；测试模式不创建实际键盘发送器。
- Win32 ABI：64 位 `INPUT` 为 40 字节，F13 虚拟键码 124，成对按下/松开事件字段正确。
- 实际单文件 EXE 自检：默认停止，开始时禁用频率等控件，10 Hz 开始与停止，停止后计数稳定，改为 20 Hz 再次开始，以及停止后控件恢复。
- 实际 EXE 可显示中文界面；使用桌面工具点击测试模式、开始、停止、频率调节及关闭。一次测试运行在界面显示 120 次 / 12.0 秒。打开程序默认 0 次且已停止。
- 修复初始窗口的底部提示裁切；最终窗口按实际字体/DPI请求尺寸设置最小值，已确认提示完整可见。
- EXE 为 Windows x64 GUI 子系统、版本 1.0.0，无控制台；可独立启动，无须用户安装 Python。

## 证据边界

自动测试与本次桌面按钮验收均使用不发送按键的测试模式。未对当前所有软件的 F13 绑定、管理员窗口、锁屏、安全桌面，
以及熄屏或休眠策略做真实输入验收。因此，不能据此断言所有软件都能收到 F13，或连按对系统功能完全没有影响。
`SendInput` 实际注入使用标准 Win32 调用；其权限和键盘状态限制见 README 中的微软文档。

构建后 `dist/SHA256SUMS.txt` 记录该 EXE 的校验值；本机原始自检报告位于未纳入源码的 `build/exe-smoke-test.json`。
